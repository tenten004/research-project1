# 診断項目と白質病変の関連解析

## 対象

- 患者数: 1,146人（ID重複なし）
- WM grade >= 1: 595人 (51.9%)
- WM grade >= 2: 153人 (13.4%)
- 年齢・性別調整から除外される欠損例: 0人

## 方法

- 粗関連: 2 x 2表、Fisherの正確確率検定、オッズ比と95%信頼区間
- 調整関連: ロジスティック回帰（年齢、性別で調整）
- 多重比較: 全14比較にBenjamini-Hochberg法を適用（FDR q値）
- 主解析: HT_C、DM_C、HL_C、himan。*_Dは部分集合のため補助解析

## 結果

調整後に q < 0.05 となった関連:
- 高血圧 (HT_C) / 白質病変あり (WM grade >= 1): aOR 1.80 (95% CI 1.29-2.51), q=0.009

主解析で調整q値が最小だった組合せ:
- 高血圧 (HT_C) / 白質病変あり (WM grade >= 1): aOR 1.80 (95% CI 1.29-2.51), q=0.009

## 解釈上の注意

- 横断データの関連であり、診断項目が病変を引き起こしたことは示しません。
- 年齢・性別のみを調整しています。治療、喫煙、他の代謝因子などの残余交絡があります。
- データ上、各 *_D=1 は同じ疾患の *_C=1 に完全に含まれます。C/Dの臨床的定義はコードブックで確認が必要です。
- ネットワーク図は関連の要約です。線の有無や太さだけで結論せず、95%信頼区間とq値を確認してください。
